# 🛒 Minhas Compras

Aplicação web desenvolvida para auxiliar na organização e no controle, permitindo gerenciar o estoque da **Despensa**, planejar a **Lista de Compras** e registrar os itens **Comprados** com prazos de validade e durações estimadas.

---
## Tecnologias Utilizadas

O projeto foi desenvolvido utilizando tecnologias web nativas e modernas, sem necessidade de frameworks complexos:
* **HTML5**: Estruturação semântica de todas as telas e componentes.
* **CSS3**: Estilização visual customizada e layout responsivo.
* **JavaScript**: Lógica da aplicação.
* **Google Fonts**: Utilizando a fonte *Itim*.
